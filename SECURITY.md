# Security Policy

This repository is a static Portfolio site. Security-sensitive issues usually involve exposed personal information, unsafe third-party links, build/deploy configuration, or public metadata.

## Supported Versions

Security fixes target the current `main` branch.

## Reporting A Vulnerability

Open a private GitHub security advisory or contact the maintainer through the GitHub profile. Do not include private personal information in public issues.

## Safe Maintenance

- Keep contact information and public metadata intentional.
- Do not commit secrets, `.env` files, analytics tokens, or private form configuration.
- Validate static export before pushing public content changes.
