## Problem

Raw packet analysis is powerful but hard to hand to another engineer or stakeholder. The useful version needed to connect capture, detection, diagrams, telemetry, persistence, reporting, and dashboard state without becoming a set of unrelated scripts.

The most recent hardening pass focused on consistency and runtime smoothness: offline replay and live capture now share the same analysis service, dashboard state is backed by SQLite, and heavy UI work stays behind tabs until the operator asks for it.

## Architecture

- Packet ingestion adapters emit normalized packet dictionaries before the shared `AnalysisPipeline` builds summaries, tracks flows, runs detectors, captures parser errors, and records runtime metrics.
- The persistence layer writes runs, flows, alerts, DPI artifacts, and metrics to a configurable SQLite database with explicit transactions and bulk insert support.
- Output surfaces include SQLite state, markdown and JSON report artifacts, lazy Mermaid diagrams, benchmark JSON, and a FastAPI dashboard that reads database state first.

## Security and observability

The project treats explainability as part of detection quality. A finding is more useful when it includes the traffic path, why the rule fired, and where the operator should look next.

That is also why the dashboard was redesigned around an operator first viewport: verdict, upload/replay controls, key metrics, latest incidents, and next steps are visible immediately. Glossary content, diagrams, report markdown, and larger tables are progressively loaded behind help drawers and tabs.

## Validation

- `PYTHONPATH=src .venv/bin/python -W default -m unittest discover -s tests -p 'test_*.py'` passed with 69 tests.
- `scripts/benchmark_pipeline.py --pcap samples/test.pcap --json /private/tmp/enterprise-nids-ui-benchmark.json --parser dpkt --no-dpi` produced benchmark JSON for parser throughput, flow count, memory, detection latency, report latency, and SQLite write latency.
- Browser verification showed no console errors on the redesigned dashboard, no Mermaid SVGs or report markdown rendered on initial load, and a 393-node initial DOM.

## Result

The project now works as a more consistent end-to-end detection platform with offline PCAP replay, live capture, shared analysis logic, SQLite-first dashboard state, report artifacts, deterministic fixtures, benchmark scripts, and a faster web dashboard.
